CELEX Dutch Tagger

The CELEX Dutch Tagger tags words with their lexical entries (pronunciations, frequency, etc.) according to the CELEX Dutch lexicon , which can be purchased from the LDC, who provide a number of text files for the lexicon.

Configuration parameters are encoded as a URL query string, e.g.
tokenLayerId=orthography&tagLayerId=phonemes&encoding=DISC

Parameters are:

tokenLayerId
Input layer from which words come.
transcriptLanguageLayerId
Transcript attribute for overall language, so the annotator can avoid tagging non-Dutch transcripts.
phraseLanguageLayerId
Layer for annotating phrases in a different language, so the annotator can avoid tagging non-Dutch phrases.
targetLanguagePattern
Regular expression for the ISO language codes of the languages to target, or blank for all.
sql
SQL for querying the CELEX relational database in order to look up the desired lexical tag(s). The query should includ one parameter ? for the input token label (usually the word orthography). Standard values are:
  • "Syllables From Phonology" - 
    SELECT PhonStrsDISC
FROM cxnl_wordformphonology
WHERE BINARY REPLACE(REPLACE(REPLACE(PhonStrsDISC, '-',''), '\"',''),'\\'','') = BINARY ?
ORDER BY LOCATE('\\'', PhonStrsDISC) DESC
  • "Phonology" - 
    SELECT REPLACE(REPLACE(REPLACE(PhonStrsDISC, '-',''), '\"',''),'\\\'','')
FROM cxnl_wordformphonology
INNER JOIN cxnl_wordformortho ON cxnl_wordformphonology.IdNum = cxnl_wordformortho.IdNum
WHERE cxnl_wordformortho.WordDia = ?
  • "Syllable Count" - 
    SELECT CHAR_LENGTH(REPLACE(REPLACE(REPLACE(REPLACE(PhonCVBr, 'V',''), 'C',''), 'S',''),']',''))
FROM cxnl_wordformphonology
INNER JOIN cxnl_wordformortho
ON cxnl_wordformphonology.IdNum = cxnl_wordformortho.IdNum
INNER JOIN cxnl_wordform
ON cxnl_wordformortho.IdNum = cxnl_wordform.IdNum
WHERE cxnl_wordformortho.WordDia = ?
ORDER BY cxnl_wordform.Inl DESC, cxnl_wordform.IdNum
  • "Morphology" - 
    SELECT
COALESCE(CONCAT(COALESCE(cxnl_lemmamorphologyparse.Imm,cxnl_lemma.HeadDia,''), ' ', REPLACE(cxnl_wordformmorphology.FlectType, ',', CONCAT('|', COALESCE(cxnl_lemmamorphologyparse.Imm,cxnl_lemma.HeadDia,''), ' '))),'')
FROM cxnl_wordformmorphology
INNER JOIN cxnl_wordformortho ON cxnl_wordformmorphology.IdNum = cxnl_wordformortho.IdNum
INNER JOIN cxnl_wordform
ON cxnl_wordformortho.IdNum = cxnl_wordform.IdNum
INNER JOIN cxnl_lemma ON cxnl_wordform.IdNumLemma = cxnl_lemma.IdNumLemma
INNER JOIN cxnl_lemmamorphologyparse ON cxnl_wordform.IdNumLemma = cxnl_lemmamorphologyparse.IdNumLemma
WHERE cxnl_wordformortho.WordDia = ?
ORDER BY cxnl_lemma.Inl DESC
  • "Syntax" - 
    SELECT cxnl_wordclass.Label
FROM cxnl_wordformortho
INNER JOIN cxnl_wordform
ON cxnl_wordformortho.IdNum = cxnl_wordform.IdNum
INNER JOIN cxnl_lemma ON cxnl_wordform.IdNumLemma = cxnl_lemma.IdNumLemma
INNER JOIN cxnl_lemmasyntax ON cxnl_wordform.IdNumLemma = cxnl_lemmasyntax.IdNumLemma
INNER JOIN cxnl_wordclass ON cxnl_lemmasyntax.ClassNum = cxnl_wordclass.ClassNum
WHERE cxnl_wordformortho.WordDia = ?
ORDER BY cxnl_lemma.Inl DESC
  • "WordForm Frequency" - 
    SELECT Inl
FROM cxnl_wordformortho
INNER JOIN cxnl_wordform
ON cxnl_wordformortho.IdNum = cxnl_wordform.IdNum
WHERE cxnl_wordformortho.WordDia = ?
ORDER BY Inl DESC
  • "Lemma Frequency" - 
    SELECT cxnl_lemma.Inl
FROM cxnl_wordformortho
INNER JOIN cxnl_wordform
ON cxnl_wordformortho.IdNum = cxnl_wordform.IdNum
INNER JOIN cxnl_lemma
ON cxnl_wordform.IdNumLemma = cxnl_lemma.IdNumLemma
WHERE cxnl_wordformortho.WordDia = ?
ORDER BY cxnl_lemma.Inl DESC
tagLayerId
Output layer to which pronunciations are added.
