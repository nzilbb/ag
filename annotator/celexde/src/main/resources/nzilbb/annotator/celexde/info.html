CELEX German Tagger

The CELEX German Tagger tags words with their lexical entries (pronunciations, frequency, etc.) according to the CELEX German lexicon , which can be purchased from the LDC, who provide a number of text files for the lexicon.

This tagger can load the data from these text files into its own databases, and from there annotate word tokens with lexical information, including:

  • standard phonemic transcriptions - e.g. differenten → dɪfərεntən
  • morphological information - e.g. differenten → differ+ent Pos-en
  • possible syntactic category - e.g. difference → A
  • frequency data
  • lemma
  • syllable count

The annotator also supports automatically tagging short hesitations with pronunciations. Orthographies with trailing '~' are recognized as short hesitations e.g.

  • s~ → s@
  • se~ → s@
  • a~ → {
  • ph~ → f@

Getting the CELEX German lexicon files

The CELEX German files are available under a non-free license, and must be acquired seperately from this annotator. You can buy a license to use the CELEX German data from the LDC: https://catalog.ldc.upenn.edu/LDC96L14
