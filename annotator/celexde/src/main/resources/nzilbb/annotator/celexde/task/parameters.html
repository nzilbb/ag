CELEX English Tagger

The CELEX English Tagger tags words with their lexical entries (pronunciations, frequency, etc.) according to the CELEX English lexicon , which can be purchased from the LDC, who provide a number of text files for the lexicon.

Configuration parameters are encoded as a URL query string, e.g.
tokenLayerId=orthography&tagLayerId=phonemes&encoding=DISC

Parameters are:

tokenLayerId
Input layer from which words come.
transcriptLanguageLayerId
Transcript attribute for overall language, so the annotator can avoid tagging non-English transcripts.
phraseLanguageLayerId
Layer for annotating phrases in a different language, so the annotator can avoid tagging non-English phrases.
targetLanguagePattern
Regular expression for the ISO language codes of the languages to target, or blank for all.
sql
SQL for querying the CELEX relational database in order to look up the desired lexical tag(s). The query should includ one parameter ? for the input token label (usually the word orthography). Standard values are:
  • "Syllables From Phonology" - 
    SELECT DISTINCT BINARY PhonStrsDISC AS label, LOCATE('\\'', PhonStrsDISC), cxen_wordformphonologypron.Variant
FROM cxen_wordformphonologypron
WHERE BINARY REPLACE(REPLACE(REPLACE(REPLACE(PhonStrsDISC, '-',''), '\"',''),'\\'',''),'R','') = BINARY REPLACE(?,'R','')" // ignore possible-linking-r - i.e. 'R'
    +"\n ORDER BY LOCATE('\\'', PhonStrsDISC) DESC, cxen_wordformphonologypron.Variant
  • "Phonology" - 
    SELECT DISTINCT BINARY REPLACE(REPLACE(REPLACE(PhonStrsDISC, '-',''), '\"',''),'\\'','') AS label, cxen_wordformphonologypron.Variant, cxen_wordform.IdNum
FROM cxen_wordformphonologypron
INNER JOIN cxen_wordformortho
ON cxen_wordformphonologypron.IdNum = cxen_wordformortho.IdNum
INNER JOIN cxen_wordform
ON cxen_wordformphonologypron.IdNum = cxen_wordform.IdNum
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_wordformphonologypron.Variant, cxen_wordform.IdNum
  • "Syllable Count" - 
    SELECT CHAR_LENGTH(PhonStrsDISC) - CHAR_LENGTH(REPLACE(PhonStrsDISC,'-','')) + 1
FROM cxen_wordformphonologypron
INNER JOIN cxen_wordformortho
ON cxen_wordformphonologypron.IdNum = cxen_wordformortho.IdNum
INNER JOIN cxen_wordform
ON cxen_wordformphonologypron.IdNum = cxen_wordform.IdNum
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_wordform.cob DESC, cxen_wordformphonologypron.Variant,"
    +" cxen_wordform.IdNum
  • "Morphology" - 
    SELECT
COALESCE(CONCAT(COALESCE(cxen_lemmamorphologyparse.Imm,cxen_lemma.HeadDia,''),
REPLACE(COALESCE(cxen_wordformmorphology.TransInfl,''), '@','')),'')
FROM cxen_wordformmorphology
INNER JOIN cxen_wordform ON cxen_wordformmorphology.IdNum = cxen_wordform.IdNum
INNER JOIN cxen_wordformortho"
    +" ON cxen_wordformmorphology.IdNum = cxen_wordformortho.IdNum
INNER JOIN cxen_lemma ON cxen_wordform.IdNumLemma = cxen_lemma.IdNumLemma
INNER JOIN cxen_lemmamorphologyparse"
    +" ON cxen_wordform.IdNumLemma = cxen_lemmamorphologyparse.IdNumLemma
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_lemma.Cob DESC
  • "Syntax" - 
    SELECT cxen_wordclass.Label
FROM cxen_wordform
INNER JOIN cxen_wordformortho"
    +" ON cxen_wordform.IdNum = cxen_wordformortho.IdNum
INNER JOIN cxen_lemma ON cxen_wordform.IdNumLemma = cxen_lemma.IdNumLemma
INNER JOIN cxen_lemmasyntax"
    +" ON cxen_wordform.IdNumLemma = cxen_lemmasyntax.IdNumLemma
LEFT OUTER JOIN cxen_wordclass"
    +" ON cxen_lemmasyntax.ClassNum = cxen_wordclass.ClassNum
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_lemma.Cob DESC
  • "Lemma" - 
    SELECT cxen_lemma.HeadDia
FROM cxen_wordform
INNER JOIN cxen_wordformortho"
    +" ON cxen_wordform.IdNum = cxen_wordformortho.IdNum
INNER JOIN cxen_lemma ON cxen_wordform.IdNumLemma = cxen_lemma.IdNumLemma
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_lemma.Cob DESC
  • "WordForm Frequency" - 
    SELECT cxen_wordform.Cob
FROM cxen_wordform
INNER JOIN cxen_wordformortho
ON cxen_wordformortho.IdNum = cxen_wordform.IdNum
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_wordform.Cob DESC
  • "Lemma Frequency" - 
    SELECT cxen_lemma.Cob
FROM cxen_wordform
INNER JOIN cxen_wordformortho
ON cxen_wordformortho.IdNum = cxen_wordform.IdNum
INNER JOIN cxen_lemma
ON cxen_wordform.IdNumLemma = cxen_lemma.IdNumLemma
WHERE cxen_wordformortho.WordDia = ?
ORDER BY cxen_lemma.Cob DESC
tagLayerId
Output layer to which pronunciations are added.
