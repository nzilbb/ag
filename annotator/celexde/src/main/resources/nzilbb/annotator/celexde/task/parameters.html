CELEX German Tagger

The CELEX German Tagger tags words with their lexical entries (pronunciations, frequency, etc.) according to the CELEX German lexicon , which can be purchased from the LDC, who provide a number of text files for the lexicon.

Configuration parameters are encoded as a URL query string, e.g.
tokenLayerId=orthography&tagLayerId=phonemes&encoding=DISC

Parameters are:

tokenLayerId
Input layer from which words come.
transcriptLanguageLayerId
Transcript attribute for overall language, so the annotator can avoid tagging non-German transcripts.
phraseLanguageLayerId
Layer for annotating phrases in a different language, so the annotator can avoid tagging non-German phrases.
targetLanguagePattern
Regular expression for the ISO language codes of the languages to target, or blank for all.
sql
SQL for querying the CELEX relational database in order to look up the desired lexical tag(s). The query should includ one parameter ? for the input token label (usually the word orthography). Standard values are:
  • "Syllables From Phonology" - 
    SELECT PhonStrsDISC
 FROM cxde_wordformphonology
 WHERE BINARY REPLACE(REPLACE(REPLACE(PhonStrsDISC, '-',''), '\"',''),'\\'','') = BINARY ?
 ORDER BY LOCATE('\'', PhonStrsDISC) DESC
  • "Phonology" - 
    SELECT REPLACE(REPLACE(REPLACE(PhonStrsDISC, '-',''), '\"',''),'\\\'','')
 FROM cxde_wordformphonology
 INNER JOIN cxde_wordform ON cxde_wordformphonology.IdNum = cxde_wordform.IdNum
 WHERE cxde_wordform.WordDia = ?
  • "Syllable Count" - 
    SELECT CHAR_LENGTH(REPLACE(REPLACE(REPLACE(REPLACE(PhonCVBr, 'V',''), 'C',''), 'S',''),']',''))
 FROM cxde_wordformphonology
 INNER JOIN cxde_wordform
 ON cxde_wordformphonology.IdNum = cxde_wordform.IdNum
 WHERE cxde_wordform.WordDia = ?
 ORDER BY cxde_wordform.Mann DESC, cxde_wordform.IdNum
  • "Morphology" - 
    SELECT
 COALESCE(CONCAT(COALESCE(cxde_lemmamorphologyparse.Imm,cxde_lemma.HeadDia,''), ' ', REPLACE(cxde_wordformmorphology.FlectTypeDescription, ',', CONCAT('|', COALESCE(cxde_lemmamorphologyparse.Imm,cxde_lemma.HeadDia,''), ' '))),'')
 FROM cxde_wordformmorphology
 INNER JOIN cxde_wordform ON cxde_wordformmorphology.IdNum = cxde_wordform.IdNum
 INNER JOIN cxde_lemma ON cxde_wordform.IdNumLemma = cxde_lemma.IdNumLemma
 INNER JOIN cxde_lemmamorphologyparse ON cxde_wordform.IdNumLemma = cxde_lemmamorphologyparse.IdNumLemma
 WHERE cxde_wordform.WordDia = ?
 ORDER BY cxde_lemma.Mann DESC
  • "Syntax" - 
    SELECT cxde_wordclass.Label
 FROM cxde_wordform
 INNER JOIN cxde_lemma ON cxde_wordform.IdNumLemma = cxde_lemma.IdNumLemma
 INNER JOIN cxde_lemmasyntax ON cxde_wordform.IdNumLemma = cxde_lemmasyntax.IdNumLemma
 INNER JOIN cxde_wordclass ON cxde_lemmasyntax.ClassNum = cxde_wordclass.ClassNum
 WHERE cxde_wordform.WordDia = ?
 ORDER BY cxde_lemma.Mann DESC
  • "WordForm Frequency" - 
    SELECT Mann
 FROM cxde_wordform
 WHERE cxde_wordform.WordDia = ?
 ORDER BY Mann DESC
  • "Lemma Frequency" - 
    SELECT cxde_lemma.Mann
 FROM cxde_wordform
 INNER JOIN cxde_lemma
 ON cxde_wordform.IdNumLemma = cxde_lemma.IdNumLemma
 WHERE cxde_wordform.WordDia = ?
 ORDER BY cxde_lemma.Mann DESC
tagLayerId
Output layer to which pronunciations are added.
